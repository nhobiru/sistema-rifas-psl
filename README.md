# sistema-rifas-psl
Sistema de gestão e divulgação das rifas da Associação Atlética Parque São Luiz

## Rifas

- `rifa-0001.html`: Festa do Dia das Crianças.
- `rifa-0002.html`: camisa do time escolhido, 50 números a R$ 5,00.

## Google Apps Script

O arquivo `apps-script/Code.gs` atende as duas rifas no mesmo Web App:

- RIFA-0001 → aba `Controle`;
- RIFA-0002 → aba `Controle RIFA-0002`.

Depois de atualizar o Apps Script, é necessário criar uma nova versão da implantação
do Web App mantendo o mesmo endereço público.
